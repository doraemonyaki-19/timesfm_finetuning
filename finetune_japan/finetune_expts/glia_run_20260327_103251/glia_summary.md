## Key Insights

1. **Horizon-weighted loss works.** Exponential decay `weight[i] = exp(-1.0 * i / 128)` across output positions successfully trades mid-horizon accuracy for short+long horizon gains. This is a novel finding — the loss function directly shapes which output positions get optimized in the single-pass decoder output.

2. **Data × loss interaction is destructive.** Semiconductor-heavy training data and horizon-decay loss interact negatively when combined. The sector data changes which output positions carry learnable signal; the decay changes which positions get gradient. When both are applied, they fight rather than complement. This was predicted by the Methods supervisor and confirmed experimentally.

3. **60d dead zone is structural.** The 60d horizon sits at a characteristic scale where neither local dynamics (14d) nor long-range trend extraction (120d) dominates. 8035.T (Tokyo Electron) drives the regression. No configuration tested fixed this. The Domain supervisor identified this as analogous to the turbulent cascade intermediate scale.

4. **Gentler decay outperforms stronger decay.** decay=1.0 beats decay=2.0 at both 14d AND 120d. Positions 30-90 serve as autoregressive context for positions 91-128. Starving them with aggressive decay (2.0) hurts long-horizon quality. This is a curriculum effect on the output patch.

5. **val_loss threshold confirmed.** The 0.015 NaN boundary from US experiments held exactly for Japan original data. Semi data checkpoints survived at higher val_loss (0.020-0.022) — threshold may be data-dependent, but staying below 0.015 is safe.

## Evaluation Framework Recommendations

- **n=3 eval tickers is critically underpowered.** The 120d improvement (+2.20pp) has std=2.88% and is not statistically significant by conventional thresholds. Future runs should expand to 5-6 eval tickers.
- **Rolling eval (15 windows) is essential.** Single-window evaluation has ~1pp noise. All results in this run used 15-window rolling eval.
- **Training-ticker validation is informative.** The eval-improves-but-training-regresses pattern for hdecay_1.0 suggests error redistribution, not pure improvement. This is a useful diagnostic.
- **The 60d dead zone may require horizon-specific evaluation.** Reporting a single "best model" across all horizons masks the structural tradeoff.
