## Data-pipeline note (this run)

The 06-22, 06-29, and 07-06 scheduled runs had **silently failed** — yfinance rate-limited
the 39 sequential per-ticker downloads, so MTM/borrow/expiry froze (unrealized stuck at
+$6,567, `days_held` stuck at 22) while the log still reported "success." Fixed in
`paper_trade.py` this run: a single **batched** download with retry/backoff, an explicit
**abort** if all downloads fail (state left untouched rather than advancing on stale prices),
and a per-ticker stale-price warning. Today's run fetched all 29 unique tickers in one
request with zero misses.
